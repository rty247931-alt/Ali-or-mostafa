# الإصدار الرئيسي 2.0 — 1 نوفمبر 2026

## قاعدة الإصدار
- الإصدار الرئيسي الوحيد المخطط له في 1 نوفمبر 2026 الساعة 00:00 بتوقيت القاهرة.
- لا تُنشأ إصدارات منفصلة لخطة نوفمبر–مارس السابقة؛ تُجمع كلها في إصدار واحد.
- تاريخ فتح صفحة التحديثات ليس إثباتًا لاكتمال الميزات أو موافقة تلقائية على النشر.

## نطاق العمل المطلوب

### المتجر وتجربة العميل
- مراجعة تصميم الصفحة الرئيسية وصفحات التصنيفات والمنتج والسلة والدفع على الهاتف والكمبيوتر.
- البحث والفلاتر والترتيب، المنتجات المشابهة، والمفضلة.
- التأكد من أن اللون والمقاس يعكسان المخزون الفعلي، وعدم إظهار مخزون غير متاح على أنه متاح.
- كوبونات وعروض محددة المدة بقواعد تحقق على الخادم.
- نقاط ولاء ومزايا للعملاء العائدين، مع سجل واضح للنقاط ومنع احتسابها مرتين.
- متابعة الطلب والفاتورة وقائمة تجهيز الطلبات.

### الإدارة والتقارير
- مبيعات وأرباح حسب فترة مع تعريف موثق للأرباح والتكاليف المستخدمة.
- مقارنة الفترات والمنتجات الأفضل مبيعًا وتنبيهات انخفاض المخزون.
- أدوار الموظفين وفحص الصلاحيات في الخادم لكل عملية إدارية.
- سجل تدقيق للعمليات الحساسة، بما فيها تغيير السعر والمخزون وحالة الطلب.
- مراجعة إيصالات المحافظ الإلكترونية وتوثيق قرار المراجعة.
- تحسين إدارة النسخ الاحتياطي والاستعادة.

## بوابات القبول الإلزامية
1. `npm ci` ينجح.
2. `npm run typecheck` ينجح.
3. `npm test` ينجح.
4. `npm run build` ينجح.
5. `SMOKE_OK=1 npm run smoke` على قاعدة تطوير فقط.
6. اختبار الصلاحيات والتسعير والمخزون والكوبونات والولاء وعدم تكرار العمليات.
7. تجربة دفع تجريبية ومراجعة إيصال محفظة من البداية للنهاية.
8. تجربة موبايل وكمبيوتر، وقياس أخطاء المتصفح وسجلات الخادم.
9. اختبار استعادة نسخة احتياطية على قاعدة منفصلة.
10. مراجعة متغيرات البيئة والأسرار والتراجع إلى النسخة السابقة.

## النشر
لا يُفعّل زر «تحديث» حتى يُجهّز مسؤول المشروع مسار نشر موثوقًا بصلاحيات مخزنة كأسرار في خدمة CI/CD، ويتحقق من نجاح البناء والاختبارات، ويعرض نتيجة النشر الفعلية. لا توضع رموز Vercel أو GitHub في المتصفح أو في مستودع الكود. لا يتم رفع ملفات تشغيلية أو تغيير قاعدة الإنتاج من صفحة الإدارة مباشرة.

## الحالة الحالية
صفحة `/admin/updates` تعرض موعد الإصدار ونطاقه فقط. الميزات المذكورة هنا هي نطاق مخطط وليست إعلانًا بأن تنفيذها أو اختبارها قد اكتمل. يلزم ربط الصفحة بقائمة التنقل الإدارية الحالية بعد مراجعة ملفاتها، وتشغيل الاختبارات في بيئة المشروع قبل الدمج.
